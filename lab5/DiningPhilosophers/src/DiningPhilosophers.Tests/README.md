# Тесты для проекта "Обедающие философы"

Этот проект содержит комплексные Unit тесты для системы обедающих философов.

## Структура тестов

### 1. PhilosopherSimulationTests.cs
Тесты для проверки переходов между состояниями философа:
- Начальное состояние (Thinking)
- Переход Thinking → Hungry
- Переход Hungry → Eating (при наличии вилок)
- Сохранение состояния Hungry при недоступности вилок
- Переход Eating → Thinking после завершения еды
- События и метрики

### 2. StrategyTests.cs
Тесты для стратегий принятия решений:
- **NaiveStrategy**: проверка случайного выбора вилок
- **ResourceHierarchyStrategy**: проверка детерминированного порядка взятия вилок
- Проверка поведения в различных состояниях

### 3. DeadlockTests.cs
Тесты для проверки deadlock ситуаций:
- Возможность возникновения deadlock в NaiveStrategy
- Предотвращение deadlock в ResourceHierarchyStrategy
- Обнаружение deadlock ситуаций
- Разрешение deadlock при освобождении ресурсов

### 4. MetricsCalculatorTests.cs
Тесты для калькулятора метрик:
- Инициализация симуляции
- Подсчет съеденных блюд
- Расчет пропускной способности (throughput)
- Среднее время ожидания
- Использование вилок (utilization)
- Потокобезопасность

### 5. ForkManagerTests.cs
Тесты для менеджера вилок:
- Инициализация
- Получение вилок по ID
- Получение всех вилок
- Начальное состояние вилок

## Запуск тестов

```bash
dotnet test
```

## Используемые технологии

- **xUnit** - основной фреймворк для тестирования
- **Moq** - для создания mock-объектов (при необходимости)
- **.NET 9.0** - целевая платформа

## Требования к тестам

✅ Все тесты изолированы и независимы  
✅ Тесты покрывают бизнес-логику  
✅ Тесты проверяют стратегии принятия решений  
✅ Тесты проверяют метрики  
✅ Тесты проверяют deadlock ситуации
